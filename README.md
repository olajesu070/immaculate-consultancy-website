## Development & Deployment

No dependencies or build steps required. Simply open `index.html` in any modern web browser or deploy directly to **Vercel**, **Netlify**, or **GitHub Pages**.

```bash
# Clone the repository
git clone https://github.com/olajesu070/immaculate-consultancy-website.git

# Navigate into directory
cd immaculate-consultancy-website

# Launch a local server (Python)
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.
